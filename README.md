This repo is an internship project I am currently doing at Hacksecure  

The first Project is a password strength checker using Python How it works is that after running the .py file user is asked to enter the password Based on the given input it gives the strength of the password based on the length of the password, 
  no characters are used, no digits are used, and no capital letters are used in the password. Based on that, it gives output as weak, moderate, or strong 

The Second Project is a port scanner to check open ports using Python. How it works is that after running the .py file user is asked to enter an IP address and port range, then the scan begins to check the open ports in the given IP address and 
Given port range.
